# TIC TAC THREE — Современные крестики-нолики

Красивая, современная игра крестики-нолики 3×3 с выбором дизайна и режимами.

## ✨ Особенности

**Поле:** классическое 3×3 с анимациями, подсветкой выигрышной линии, конфетти.

**3 Дизайна:**
- **Nebula** — темный, неоновый, стеклянный морфизм, космические градиенты
- **Frost** — светлый минимализм, frosted glass, мягкие тени
- **Clay** — пастельный клейморфизм, мягкий 3D, теплые тени

**3 Набора фигур:**
- **Classic** — чистые × ○ геометрические
- **Cosmic** — ✦ звезда vs ☾ луна
- **Neo Pop** — ⚡ молния vs ◍ капля

**3 Режима игры:**
- 🤖 **С ботом** — 3 сложности: Легко (рандом), Средне (50% оптим), Невозможно (minimax)
- 👥 **Друг vs Друг** — на одном устройстве
- 🌐 **Онлайн** — P2P через PeerJS, создай комнату с кодом из 6 символов и играй с другом без сервера

**Правило «Три фигуры»:**
- Переключатель в левой панели
- Классика: обычные крестики-нолики
- Три фигуры: у каждого максимум 3 метки на поле, 4-й ход стирает самую старую. Ничьих нет, игра бесконечна и требует тактики. Очередь фигур показывается с подсветкой той, что исчезнет.

**Дополнительно:**
- Счётчик раундов, серии побед, ходов
- Локальное сохранение темы, фигур, статистики
- Адаптивный дизайн, клавиатурные шорткаты (R — сброс, N — следующий раунд)
- Поделиться результатом, копирование кода комнаты

## 🚀 Запуск

```bash
npm install
npm run dev
# открой http://localhost:5173
```

Собрать продакшн:
```bash
npm run build
npm run preview
```

## 🛠 Стек

- Vanilla JS (ES modules), чистый CSS с CSS-переменными для тем
- Vite для dev-сервера
- PeerJS 1.5.4 для P2P онлайн режима (https://unpkg.com/peerjs)
- Google Fonts: Syne, Space Grotesk, JetBrains Mono

Никаких фреймворков — только современный ванильный веб.

## 🎮 Как играть

1. Выбери режим слева
2. Выбери дизайн и фигуры справа
3. Включи «Три фигуры» если хочешь бесконечный тактический вариант
4. Собери 3 в ряд чтобы выиграть
